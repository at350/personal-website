# Technology marks

Most marks are bundled from the installed `simple-icons` package.

Additional local SVG sources:

- OpenAI: https://github.com/simple-icons/simple-icons/blob/14.0.0/icons/openai.svg
- Firecrawl: https://github.com/firecrawl/firecrawl/blob/main/apps/test-site/src/assets/firecrawl-logo.svg

These assets are bundled locally so they do not depend on a third-party image server during rendering or book texture capture. Brand shapes are preserved; CSS displays them in monochrome. Methods and tools without a suitable compact mark keep their full text label without invented initials.
