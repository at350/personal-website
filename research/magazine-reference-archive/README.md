# Magazine reference archive

This folder reconstructs the editorial research behind the current personal-site direction.

Start here:

- `moodboard.html` — visual evidence board using the locally saved research assets.
- `brand.md` — the full project-specific synthesis.
- `brand.json` — machine-readable sources, assets, confidence, rights notes, and style guidance.
- `sources/source-index.md` — retrieval and provenance ledger.
- `sources/motion-observations.md` — aggregate-versus-live-site behavior, pacing, interaction, and implementation risks.
- `sources/personal-mymind-index.md` — selective index of the user-supplied private inspiration space and its handling rules.
- `assets/images/` — selected publisher-hosted reference images.
- `assets/screenshots/` — dated captures of live source pages.
- `assets/screenshots/web-galleries/` — the six supplied discovery galleries plus the featured sites opened from them.
- `assets/screenshots/personal-mymind/` — private-board composites and public publication sites traced from that board.
- `assets/motion/` — local research copies of cited preview loops; never production assets.

To view the moodboard on macOS:

```sh
open research/magazine-reference-archive/moodboard.html
```

The moodboard now includes playable motion samples and a reduced-motion fallback. Serve it from a local web server if the browser restricts video playback from `file://`.

All source imagery and motion are for private design research. The mymind captures are additionally private user-provided context. Do not move any of these assets into `public/`, ship them with the deployed site, or redistribute the archive.
