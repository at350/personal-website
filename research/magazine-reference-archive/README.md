# Magazine reference archive

This folder reconstructs the editorial research behind the current personal-site direction.

Start here:

- `moodboard.html` — visual evidence board using the locally saved research assets.
- `brand.md` — the full project-specific synthesis.
- `brand.json` — machine-readable sources, assets, confidence, rights notes, and style guidance.
- `sources/source-index.md` — retrieval and provenance ledger.
- `assets/images/` — selected publisher-hosted reference images.
- `assets/screenshots/` — dated captures of live source pages.

To view the moodboard on macOS:

```sh
open research/magazine-reference-archive/moodboard.html
```

All source imagery is for private design research. Do not move it into `public/` or ship it with the deployed site.
