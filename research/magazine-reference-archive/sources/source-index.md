## Collection method

- Official publisher or creator pages were preferred.
- Live screenshots were captured at desktop width on 2026-08-11; the Edge viewport used for the private archive was 1424 × 874.
- Only a small representative set of source images was downloaded.
- Secondary archives were used for comparison and for the NYT access gap.
- Aggregate galleries were used to select candidates. Live featured sites were then opened and observed at entry and after scroll, hover, cursor movement, or layout changes where available.
- The user explicitly authorized one private mymind Smart Space in their personal Edge browser. Only publication, magazine, web-design, and interaction references from that exact space were indexed. No cookies, storage, browser history, unrelated cards, or account details were read.

## Known gaps

- The private board contains NYT Magazine imagery, but a smaller named set of exact NYT cover URLs has not yet been isolated.
- Several private-board image cards have generic filenames only; they are preserved as viewport evidence rather than misattributed individual assets.
- Coverjunkie is dynamic, so its captured selection will drift from the live archive.
- NOTHIN' remained in a long loader during the live visual capture. Its motion record combines the observed loader with Awwwards' public element notes.
